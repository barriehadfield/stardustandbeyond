# Stardush

Static, image-first portfolio site, served from GitHub Pages. Plain HTML/CSS/JS
with no runtime dependencies — the HTML pages are generated from a single content
file and committed. Dark theme with a coral accent and a swipe / pinch-zoom lightbox.

Scaffolded from the `henridavies` template. **Replace the placeholders** before
going live: `SITE` (name, role, url) in `scripts/site-data.mjs`, the `CNAME`
file (create it with your domain), and the share-card copy in `source/og-card.html`.

## Structure

```
index.html                  Home — landing (hero + section cards)   ┐
paintings.html              Paintings gallery                       │ generated by
photography.html            Photography gallery                     │ `npm run build`
fashion.html                Fashion gallery (article-led)           │ — do not hand-edit
interiors.html              Interiors gallery                       │
for-sale.html               Works available to purchase             │
about.html                  Biography                               ┘
css/style.css               Styles (single dark theme)              ┐ hand-written
js/site.js                  Mobile nav + swipe/pinch-zoom lightbox  ┘ site assets

scripts/site-data.mjs       Content (single source of truth: SITE, galleries, bio, prices)
scripts/build-pages.mjs     Generates the HTML pages from site-data
scripts/optimize-images.mjs Generates public/ derivatives from source/
scripts/dev-serve.py        No-cache static dev server

public/images/              Web-optimized images served to visitors (generated)
source/images/              Full-resolution originals (archive; drop new work here)
source/og-card.html         Design source for the 1200x630 social share card
```

## Editing

- **Site identity:** edit `SITE` in `scripts/site-data.mjs` (name, role, url), then `npm run build`.
- **Page copy / gallery order / titles:** edit the arrays in `scripts/site-data.mjs`, then `npm run build`.
- **Add or replace an image:** drop the original into the relevant
  `source/images/<section>/` folder, run `npm run optimize`, add its filename
  (without extension) to the matching array in `scripts/site-data.mjs`, then `npm run build`.

## Commands

```bash
npm install        # once, installs sharp (build-time only)
npm run optimize   # source/images -> public/images (webp + jpg + thumbnails)
npm run build      # regenerate the HTML pages
npm run dev        # preview at http://localhost:8000 (no-cache, so refreshes show changes)
```

The build is robust to empty data: a fresh clone with no images still builds every
page (empty galleries, copy-only hero). Populate `site-data.mjs` to fill them in.

## Deploying to GitHub Pages

Serve from the repository root of the default branch (Settings → Pages →
Source: Deploy from a branch → `main` / `/root`). `.nojekyll` is present so files
are served as-is. Add a `CNAME` file containing your custom domain and point DNS
at GitHub Pages.
