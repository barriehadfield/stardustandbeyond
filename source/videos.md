# Videos — source

Edit this to add videos to the **Videos** tab. One row per video, in display order
(top = first). Paste the full YouTube link (or just the 11-character video id) in the
first column and a title in the second. The build turns each into an embedded player.

This file is editable on GitHub and is **not** touched by the photo importer.
